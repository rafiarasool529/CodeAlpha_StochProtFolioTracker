# CodeAlpha Stock Portfolio Tracker

## Project Description
This is a Python-based Stock Portfolio Tracker developed as part of the CodeAlpha Python Programming Internship.

It calculates the total investment value based on predefined stock prices and user-entered quantities.

## Features
- Predefined stock prices using a dictionary.
- User can enter stock symbols and quantities.
- Calculates individual stock investment.
- Displays total investment value.
- Saves portfolio details in a text file.

## Technologies Used
- Python
- Dictionaries
- Loops
- Conditional Statements
- File Handling

## How to Run
1. Download the Python source code.
2. Run CodeAlpha_StochProtFolioTracker.
3. Enter the number of stocks.
4. Enter stock symbols and quantities.
5. View the total investment.
